# Atlas Muscular

Boneco anatômico clicável, com corpo masculino ou feminino (botão ♂/♀). Toque num músculo para ver os exercícios em ordem de estímulo (estudos de crescimento, EMG e biomecânica). Toque num exercício para ver os sinergistas em laranja.

- **Atlas**: modelos Detalhado, Básico e Articulações (aquecimento, mobilidade e alongamento).
- **Ficha**: treino da semana, de segunda a domingo.
- **Treino**: registro de séries, repetições, carga e anotações.
- **Progresso**: mapa de calor dos músculos treinados na semana ou no dia, contando as séries marcadas (1 para o alvo, ½ para sinergistas).

Abra pelo link do GitHub Pages no Safari e use Compartilhar → Adicionar à Tela de Início para instalar como app.
