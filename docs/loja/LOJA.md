## Formulários da Play Store

### Segurança dos dados (Data safety)

- O app coleta ou compartilha dados? **Sim** (só de quem entra com o Google).
- Os dados são criptografados em trânsito? **Sim** (Firebase usa HTTPS).
- O usuário pode pedir para apagar? **Sim**: no app (Configurações › Conta › Apagar minha conta) e pela página de suporte.
- Dados **compartilhados** com terceiros: **nenhum** (o Firebase é prestador de serviço, não conta como compartilhamento).
- Dados **coletados** (todos opcionais, só com conta; finalidade: Funcionalidade do app e Gerenciamento da conta; não são processados de forma temporária):
  - Informações pessoais › **Nome**, **Endereço de e-mail**, **IDs do usuário**.
  - Saúde e fitness › **Informações de condicionamento físico** (treinos, cargas, peso do corpo, cardio).
- Não coleta: localização, contatos, fotos, áudio, mensagens, informações financeiras, histórico de navegação, identificadores de publicidade, dados de uso/análise.
- Link da política: https://holmgds-gui.github.io/atlas-muscular/privacidade.html

### Classificação do conteúdo (questionário IARC)

- Categoria: **Referência, notícias ou educação** (ou "Todos os outros tipos de app").
- Violência, sangue, medo, sexo, palavrões, drogas, álcool, tabaco, jogos de azar: **Não** para tudo (o crânio do boneco 3D é anatômico).
- Os usuários interagem ou trocam conteúdo entre si? **Não** (os cartões para Stories saem pelo compartilhar do celular, não dentro do app).
- Compartilha a localização? **Não**. Compras digitais? **Não**.
- Resultado esperado: **Livre / Everyone / PEGI 3**.

- Governo, notícias, empréstimos, VPN: **Não**.
