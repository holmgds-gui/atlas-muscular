# Fontes e links

Todas as fontes usadas para montar o Atlas Muscular, mais algumas extras para consulta futura.

Os nomes curtos entre colchetes, como `[ace_peito]`, são as chaves do objeto `SRC` no `index.html`.

Os links marcados com 🔎 levam a uma busca no PubMed: o estudo é conhecido, mas o endereço exato da página não foi confirmado.

## Observação

Pelland et al. e Remmert et al. foram escritos por treinadores e circularam primeiro como pré-publicações. A meta-regressão de volume de Pelland já saiu na *Sports Medicine*. Os estudos da ACE são financiados pela própria ACE, com amostras pequenas. Use os selos do app como guia, não como verdade absoluta.
